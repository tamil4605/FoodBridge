College Project Specification

FoodBridge: Smart Food Donation and Redistribution Platform

"Good Things Deserve to Be Shared." A full-stack social impact platform built strictly using the approved college academic tech stack.

Project Objective & Problem Statement

Every year, thousands of tons of perfectly wholesome cooked meals, bakery products, and perishable rations are discarded by catering establishments, hotels, and individual households, while simultaneously vulnerable populations in orphanages, old age homes, and temporary shelters face malnutrition.

FoodBridge eliminates resource distribution friction by connecting donors with verified non-governmental organizations and charity kitchens within localized city zones in Chennai, Tamil Nadu.

Approved Technology Architecture

Layer Technology Strict Academic Guidelines Compliance
Backend Framework Spring Boot 3.3.4 (Java 21) Clean layered architecture: Controller → Service → Repository → Entity → DTO
Database & ORM MySQL 8.0 with Spring Data JPA & Hibernate Normalized schema with relationships, enumerated statuses, and timestamps
Security & Auth Spring Security & BCrypt Role-based access control with session management
Frontend Views Thymeleaf Server-Side Rendering Server-rendered templates with dynamic fragment composition
Client Scripts & Styling Vanilla JavaScript + CSS3 + Bootstrap Asynchronous Fetch API, modern styling in Forest Green & Fresh Green
Build Tool Apache Maven Standard pom.xml dependency management

Course Demo Mode Notice

Simulated Demonstration Sandbox: All payment and transaction modules in this application run exclusively in demo simulation mode. No credit cards, bank accounts, or UPI PINs are ever requested.

Supported Roles
1. Individual Donor - Share excess groceries, home-cooked food, clothes & books
2. Restaurant / Business Donor - Hotels, banquet halls & bakeries donating bulk surplus meals
3. Recipient Organization - NGOs, orphanages & old age homes receiving donations & publishing community needs
4. Administrator - Organization verification, audit trails, and platform moderation
